# ASWIN A K - ODOO ARCHITECT PORTFOLIO

## DEMO
A full brutalist rebuild. No generic templates. Just massive typography, raw data-driven layouts, and extreme high-contrast architecture.

![Brutalist Portfolio Demo](./public/demo.webp)

## OVERVIEW
A high-performance, brutalist portfolio designed for maximum visual impact. Built with React, Tailwind CSS, and Framer Motion. 
Focuses purely on an engineering mindset, swapping soft UI gradients for stark borders, pure black and white palettes, and an industrial 'acid green' accent.

## STACK
*   **CORE:** React + Vite
*   **STYLING:** Tailwind CSS (Custom Brutalist Theme)
*   **ANIMATION:** Framer Motion
*   **ICONS:** Lucide React

## FEATURES
*   **Massive Typography:** Anton & Manrope fonts optimized for impact.
*   **High Contrast:** Pure Black `#0f0f0f`, Stark White `#ffffff`, Acid Green `#ccff00`.
*   **Brutalist Splash Screen:** Custom load sequence with jumping system compilation percentages.
*   **Functional Contact Form:** Integrated directly with Web3Forms to securely bypass backend server requirements.
*   **Mobile Optimized:** Fully fluid brutalist components that scale constraints elegantly.

## DEPLOYMENT INSTRUCTIONS
1. Clone this repository.
2. Run `npm install` to download dependencies.
3. Rename `.env.example` to `.env`.
4. Add your Web3Forms access key natively: `VITE_WEB3FORMS_KEY=your_generated_access_key`
5. Run `npm run dev` to launch the local development server.
6. Deploy to your preferred platform (Vercel, Netlify, Cloudflare Pages) for instant global architecture.
